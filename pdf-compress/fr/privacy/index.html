PDF Compressor Offline

Politique de confidentialité

Dernière mise à jour : 17 mai 2026

PDF Compresseur Offline compresse les PDF directement sur votre appareil. Cette politique explique quelles données sont traitées et comment les achats sont gérés.

ConfidentialitéConditionsSupportInfos appEULA Apple

1. Traitement hors ligne

Les PDF sont traités sur votre appareil. L’app n’envoie pas vos PDF à nos serveurs pour les compresser. Le fichier original n’est pas modifié ; une nouvelle copie compressée est créée lorsque c’est possible.

2. Fichiers et documents

Les PDF sélectionnés sont utilisés uniquement pour l’action de compression demandée. Le résultat est enregistré ou partagé seulement si vous le choisissez. L’app ne conserve pas de bibliothèque de fichiers compressés.

3. Informations stockées sur l’appareil

L’app peut stocker des préférences locales et un état d’utilisation limité, comme les compteurs gratuits et l’état d’accès Premium.

4. Achats

Premium est proposé comme achat unique à vie via l’Apple App Store. RevenueCat peut être utilisé pour valider, restaurer et gérer l’accès Premium.

5. Données non collectées

Aucun compte n’est requis, le contenu des PDF n’est pas collecté, aucune localisation précise n’est collectée et aucun suivi publicitaire n’est utilisé.

6. Support

Pour la confidentialité ou le support : info@aristophia.com.
